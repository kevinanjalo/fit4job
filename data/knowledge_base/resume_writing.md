# Resume Writing for Technology Roles

A technology resume is scanned in seconds, so lead with impact. Each bullet
should follow the pattern: action verb, what was built or changed, technology
used, and a measurable outcome. Quantify wherever honest numbers exist:
latency reduced, users served, revenue affected, coverage increased. Keep the
document to one page for under ten years of experience, use consistent
formatting, and order sections by relevance to the target role. Mirror the
vocabulary of the job description for genuine skills so both human reviewers
and applicant tracking systems recognise the match, but never list skills you
cannot defend in an interview. Projects with links to code carry more weight
than course lists. Remove objectives and generic soft-skill claims; let
evidence speak. Tailor the top third of the resume for each application.
