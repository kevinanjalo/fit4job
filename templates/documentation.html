Platform documentation

A quick reference for users and administrators. Full API documentation is auto-generated at /docs (Swagger UI) and /redoc.

For job seekers

Use Career tools to upload a resume, run hybrid semantic matching, analyse skill gaps against specific jobs, generate interview questions from a job description, get resume feedback and build a personalised learning roadmap. Semantic search on the Jobs page lets you describe a role in plain language.

For administrators

The Admin dashboard covers job management, user management with role-based access control, taxonomy editing with hierarchical and overlapping skill relationships, roadmap JSON editing, RAG knowledge base updates and re-indexing, vector index rebuilds, analytics, system monitoring, application and audit logs, configuration and backups.

Matching model

Final score = 0.7 x SBERT cosine similarity (FAISS HNSW retrieval, PCA-reduced embeddings) + 0.3 x Jaccard overlap of taxonomy-expanded skill sets. Weights are adjustable in Admin, Configuration.

Model integration

Drop your trained artifacts into models_store/ (SBERT directory, pca_model.pkl, faiss_hnsw.index). The services load them automatically at startup; no code changes required. Without them, transparent fallbacks keep the platform functional.
